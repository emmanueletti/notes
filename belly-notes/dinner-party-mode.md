# Dinner party mode

## opportunity

people want to host dinner parties. how can we give a central place to organize
all the moving pieces of planning and executing a dinner party.

## what is involved in organizing an event

- create an event
- pick the meals that go into the event
- add collaborators to a shared workspace so they can choose what they want to
  bring
- if doing a plated event organize the order of the meals
  - every event has pretty standard 'set list' for foods
  - appetizers -> mains -> desserts
  - anything else can be added later
- create an order of events with times
  - arrival, appetizers, mains, desserts,
- this order now helps you plan
  - ai feature: create an execution to get meals ready by the end.
  - the app asks how you want to structure your event, when you want the meals
    to eb reaedy by etc

- a 'party' can be added to a planned date
  - parties show up on the hime page as a reminder (add to cal?)
- can have collaborators, like google docs you'll need a belly account to see
  and interact with a party
- a collaborator can add a dish type they want to contribute to the party in the
  parties section

- a party is made up of:
  - a host
  - location
  - arrival time
  - instructions
  - dishes
    - has a recipe
    - is a kind (appetizer, main, dessert, drinks)
    - has a owner (default party host, can be moved to collaborators)
  - collaborators (who can own dishes
  - execution_plan
    - status (on track, off track, complete)
    - has many checkpoints
      - checkpoint has
        - timestamp
        - description
        - status: (pending, completed)
